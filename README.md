# Gifox — Free Offline Installer

![Category](https://img.shields.io/badge/GIF_Recorder-blue?style=flat-square)

## About

Gifox is a macOS screen-to-GIF recorder that lives in the menu bar. Capture any window or screen region as an animated GIF with configurable frame rate and quality settings. Smart cursor highlighting, looping options, and direct sharing make Gifox a quick, polished way to create GIFs for bug reports, documentation, and social media from a Mac.

## Common Problems & Limitations

- **macOS Only** — No Windows version
- **Commercial License** — Paid application
- **File Size** — High-quality GIF recordings produce large files without compression
- **Frame Rate Limits** — Very high frame rate GIFs may not be supported by all platforms
